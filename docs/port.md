### PORT ROM For RC11 2021 / Narzo 50I
Port ROM allows us to run ROMs from other phones to this device. For 32-bit ROMs, the vendor used is the stock vendor, while for 64-bit ROMs, the vendor is ported from the ZTE A52.


### List Port ROM
* 32BIT ROM
  * Android 12 (SDK31)
    * HIOS11 From Tecno POP7
    * ItelOS From Itel S18
    * Realme UI GO From Realme c30s
  * Android 13 (SDK33)
    * DOKEUI4.0 From BlackView wave 6c
* 64BIT ROM
  * Android 11 (SDK30)
    * MYOS11 From ZTE A52
  * Android 13 (SDK33)
    * MYOS13 From ZTE A54
    * ONEUI5 From Samsung A03
    * HIOS13 From Tecno Pop8
    * DOKEUI4.0 From BlackView A52
    * XOS13 From Infinix Smart8
    * ColPadOS From Colpad cp12
  * Android 14 (SDK34)
    * HyperOS (this is GSI but ported)

### BUGS
Some ports have BUGs, some don't, if the ROM has BUGs, you can fix it by flashing the modules inside port archive via a root manager like BakaSU/KernelSU

### Compatibility
* Both custom boot.img and port rom can be installed on any firmware version on this device if you do it right, for more detailed information please read via telegram or ask it via git issue

### Notes
* If you have the 2/32 variant, it is best to use the 32bit port so that there is no lag when used, for 3/32 and 4/64 you are free to use both(32/64bit port)
